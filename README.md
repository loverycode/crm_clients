# ClientFlow - Система учёта клиентов

## Назначение

Приложение предназначено для автоматизации учёта клиентов компании. Оно позволяет менеджерам по продажам и администраторам хранить информацию о клиентах, отслеживать их статус и быстро находить нужные контакты, что повышает эффективность работы с клиентской базой.

## Целевая аудитория

- Менеджеры по продажам
- Администраторы компаний
- Сотрудники отдела маркетинга

## Предметная область

Сервис относится к классу CRM-систем (Customer Relationship Management). В рамках предметной области выделяются клиенты, их контактные данные и статусы взаимодействия. Цель системы — централизованное хранение и удобный доступ к этой информации.

## Основные сущности

- **Клиент** (Client): содержит информацию о человеке или компании (имя, контакты, статус).
- **Заявка/Заказ** (будущий этап): для связи клиентов с покупками.
- **Пользователь** (будущий этап): сотрудник, работающий с системой.

## Основные функции

- Добавление нового клиента с указанием имени, контактов и статуса.
- Просмотр списка всех клиентов.
- Поиск клиента по имени или контактным данным.
- Изменение статуса клиента (например, "Новый", "В работе", "Завершено").

## План развития

На следующих этапах планируется:

- Реализовать хранение данных в базе данных (PostgreSQL/SQLite).
- Создать веб-интерфейс на Django для удобного управления.
- Внедрить систему аутентификации пользователей (менеджеров).
- Разработать REST API для интеграции с другими системами.
- Контейнеризация приложения с использованием Docker.
- Настройка CI/CD (непрерывной интеграции и доставки).
